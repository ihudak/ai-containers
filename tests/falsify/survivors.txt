# tests/falsify/survivors.txt — the SURVIVOR LEDGER.
#
# A mutant that nothing noticed is evidence that an assertion is missing or
# cannot fail. Every one of them is written down here and classified, and
# tests/falsify/check-ledger.sh is the ratchet: a survivor with no entry, an
# entry with no classification, an entry for a mutant that no longer exists, and
# an entry for a mutant that is now KILLED each fail the gate. That is what
# stops a new hole landing silently, and what stops an amnesty outliving its
# reason.
#
# ── GRAMMAR ───────────────────────────────────────────────────────────────────
# Column 0 opens an entry; indentation continues it. Blank lines and `#`
# comments are ignored anywhere.
#
#   GROUP: <name>            optional — names the entry that follows
#   <identity>               column 0; several CONSECUTIVE lines share one entry
#     <context>              indented free text: the original line, the damage
#     GAP: <reason>          indented; or EQUIVALENT: / ENV-DEPENDENT:
#     <more reason>          indented continuation
#
# ── GAP vs EQUIVALENT vs ENV-DEPENDENT ────────────────────────────────────────
# These are DIFFERENT CLAIMS and the difference is the point of the file.
#
#   GAP:            no test kills this mutant, and one could. The suite is
#                   weaker than it should be here. A GAP that stays is a debt.
#   EQUIVALENT:     NO test could ever kill it — the mutated program is
#                   observably the same program, or the only observer lies
#                   outside this tier. The reason must say WHY no test COULD,
#                   not that none does.
#   ENV-DEPENDENT:  the VERDICT itself moves with the machine, and neither
#                   reading is wrong. Exempt from check D (obsolete amnesty) so
#                   one ledger can be correct in CI and on a developer host at
#                   once; still required to carry a non-empty reason.
#
# "Nothing currently asserts it" is a GAP written as an EQUIVALENT, and it is
# the way this file would rot. The gate can only check that a marker is present
# and its reason non-empty (an empty reason suppresses nothing, exactly as with
# `# dialect-lint: allow RULE-ID: reason`); the distinction between the three is
# a review obligation, enforced by a human reading the reason.
#
# ── ENV-DEPENDENT IS NOT SYMMETRIC, AND THAT IS DELIBERATE ────────────────────
# It is tempting to reach for it whenever two machines disagree. Which way they
# disagree decides whether it is the right marker, because the two failures it
# has to avoid are not the same failure.
#
#   SURVIVES somewhere other than CI, killed in CI  ->  ENV-DEPENDENT.
#     An unfiled survivor fails check B on that host, and a GAP filed for it
#     fails check D in CI. Only ENV-DEPENDENT can be true in both places.
#     Entry 14 (p_md5) is this shape.
#   KILLED somewhere other than CI, survives in CI   ->  STAYS A GAP.
#     Filing it ENV-DEPENDENT would buy nothing — check D is not fatal outside
#     CI, so the GAP is already safe there — and would cost the ratchet its
#     teeth: when the real assertion is finally written and the mutant dies in
#     CI too, check D is what forces the entry out, and ENV-DEPENDENT is exempt
#     from check D. The debt would then be invisible instead of retired.
#     Entries 9 and 13 are this shape (both die on macOS, on platform accidents
#     rather than on an assertion aimed at the branch) and are GAPs on purpose.
#
# Stated the short way: classify by the REFERENCE environment; record the other
# one in the prose.
#
# ── IDENTITY ──────────────────────────────────────────────────────────────────
# `<file>:<operator>:<sha1-of-the-trimmed-original-line>`, the full 40-hex
# digest exactly as tests/falsify/run.sh prints it. Never `file:line` — a line
# number is invalidated by any edit above it, while the line's own hash is not.
#
# IDENTITY IS NOT UNIQUE, deliberately: one line with two `&&` yields two
# logic-flip mutants sharing operator and sha1, and `seq`/`lineno` — both
# run-local — are the only things telling them apart. ONE ENTRY THEREFORE COVERS
# EVERY MUTANT SHARING ITS IDENTITY: colliding mutants damage the same line with
# the same operator, so they share what this file records — which line no
# assertion is watching. Where the collision is between genuinely different
# damages, the entry's prose must account for all of them.
#
# Survivors are deduplicated by (identity, mutated line) before being counted,
# so a single-clause `if [[ X ]];` — whose two cond-negate mutants produce
# byte-identical damage — is one survivor here rather than two.
#
# ── SCOPE ─────────────────────────────────────────────────────────────────────
# An entry is only checked against a run that measured its file. `run.sh
# --target tools-lib.sh` leaves every other entry unmeasured, not stale. The
# ledger is only fully verified by a run over the whole active target set.

# ══ HOW THE ENTRIES BELOW WERE CLASSIFIED ═════════════════════════════════════
# Every entry states whether ANY hermetic test kills the mutant, and that is a
# MEASURED fact, not a reading of the source: each surviving damage was applied
# to a throwaway copy of the tree and the WHOLE 52-test suite run against it.
# That measurement changed classifications outright — one damage the backlog
# recorded as "nothing exercises it" is killed by test-migrate-runme.sh — so the
# difference between "no test kills it" and "the DECLARED ORACLE does not kill
# it" is written into the entries rather than assumed away.
#
# It also produced one reading that was WRONG and is corrected here rather than
# quietly dropped: the three tests/portability.sh p_stat_meta damages were
# recorded as killed by test-allowlists.sh and test-falsify-generate.sh. They are
# not. That verdict only appears when the tier runs several workers at once, and
# it is the free-block count moving between two samples, not an assertion
# watching the branch — see entry 13 and backlog F30's addendum. RE-MEASURE AT
# --jobs 1. A verdict taken under load can be a property of the machine.
#
# Corpus (2026-08-18): tests/falsify/run.sh --jobs 6 over the nine active
# targets, TOTAL|9|251|220|27|4|7|12 — 27 SURVIVED + 4 UNPROVEN = 31 records.

# its mutants are killed, so no entry is owed for them.
#
# That line is provenance: the TOTAL of one dated run, which does not move when
# this file is edited. It deliberately no longer tallies identities or entries.
# It used to ("32 identities, 12 entries") and both had gone stale, because
# splitting one entry in two — or retiring one, as F16 did to entry 3 — changes
# a count nothing recomputes. check-ledger.sh prints both numbers on every run,
# derived from the file it is scoring, so stating them here was a second copy of
# a fact that could only ever drift away from the first.
